# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature for this repository, or contact AgentMore through https://agentmore.app.

Include a clear description, reproduction steps, affected version, and potential impact. Do not include private Markdown documents, credentials, or other sensitive information unless a secure sharing method has been agreed upon.

AgentMore will acknowledge a report as soon as practical and coordinate disclosure after a fix is available.
